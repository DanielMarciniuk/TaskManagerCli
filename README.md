# Task Manager CLI

## Português

Aplicação simples de **gerenciamento de tarefas via terminal** desenvolvida em **C# (.NET Console)**.  
Permite criar, listar, concluir e remover tarefas, salvando os dados em um arquivo **JSON** para persistência.

### Funcionalidades
- Criar tarefas
- Listar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Salvamento automático em JSON

### Tecnologias
- C#
- .NET Console
- System.Text.Json

### Como executar

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/TaskManagerCli.git
```

Entre na pasta do projeto:

```bash
cd TaskManagerCli
```

Execute o projeto:

```bash
dotnet run
````

Simple **task management application via terminal** developed in **C# (.NET Console)**.
